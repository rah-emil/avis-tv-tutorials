# Шпаргалка по git

> Самые нужные команды в одну строку. Короткие версии (`git st`, `git ph` …) — в [алиасах](git-aliases.md).

[← Назад к настройке git и gh](README.md)

## Старт

| Команда | Что делает |
|---|---|
| `git clone <url>` | Скачать репозиторий в новую папку |
| `git init` | Создать репозиторий в текущей папке |
| `git config --global --list` | Показать твои настройки |

## Каждый день

| Команда | Что делает |
|---|---|
| `git status` | Что изменено и что готово к коммиту |
| `git add <файл>` | Добавить файл в следующий коммит |
| `git add .` | Добавить все изменения в текущей папке |
| `git commit -m "текст"` | Сохранить коммит с сообщением |
| `git push` | Отправить коммиты в GitHub |
| `git pull` | Забрать изменения из GitHub |
| `git diff` | Показать, что изменилось, построчно |
| `git log --oneline` | Короткая история коммитов |

## Ветки

| Команда | Что делает |
|---|---|
| `git branch` | Список веток |
| `git switch <ветка>` | Перейти на ветку |
| `git switch -c <ветка>` | Создать ветку и перейти на неё |
| `git push -u origin HEAD` | Первый push новой ветки |
| `git merge <ветка>` | Влить ветку в текущую |
| `git branch -d <ветка>` | Удалить уже влитую ветку |
| `git cherry-pick <коммит>` | Перенести один коммит в текущую ветку |

## Worktree — несколько веток одновременно

Обычно в одной папке открыта одна ветка. `git worktree` создаёт **дополнительные рабочие папки** того же репозитория: у каждой своя ветка, а история и `.git` общие. Переключаться между ветками и прятать правки (`stash`) не нужно.

| Команда | Что делает |
|---|---|
| `git worktree add ../feature-x -b feature-x` | Новая папка `../feature-x` с новой веткой `feature-x` |
| `git worktree add ../hotfix <ветка>` | Папка для уже существующей ветки |
| `git worktree list` | Все рабочие папки репозитория |
| `git worktree remove ../feature-x` | Удалить папку (ветка и коммиты остаются) |
| `git worktree prune` | Убрать записи о папках, которые удалили вручную |

> [!TIP]
> Worktree часто используют AI-агенты (например, Claude Code): каждому агенту выдаётся своя папка с отдельной веткой, и они параллельно работают над несколькими фичами локально, не мешая друг другу и тебе.

Правило: одну ветку нельзя открыть в двух рабочих папках сразу.

## Исправить ошибку

| Команда | Что делает |
|---|---|
| `git restore <файл>` | Откатить файл до последнего коммита (**несохранённые правки пропадут**) |
| `git restore --staged <файл>` | Убрать файл из `git add`, правки остаются |
| `git commit --amend` | Поправить последний коммит (пока он не отправлен) |
| `git revert <коммит>` | Новый коммит, отменяющий указанный — безопасно для общих веток |
| `git stash` / `git stash pop` | Спрятать правки на время / вернуть их |
