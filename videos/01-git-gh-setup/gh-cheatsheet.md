# Шпаргалка по gh

> `gh` — GitHub в терминале: репозитории, pull request'ы, вход. Не заменяет `git`, а дополняет его.

[← Назад к настройке git и gh](README.md)

## Вход

| Команда | Что делает |
|---|---|
| `gh auth login` | Войти в GitHub (один раз) |
| `gh auth status` | Проверить, кто залогинен |
| `gh auth refresh` | Обновить права доступа (scopes) без нового входа |
| `gh auth logout` | Выйти |

## Репозитории

| Команда | Что делает |
|---|---|
| `gh repo clone <владелец>/<репо>` | Скачать репозиторий (git clone по имени, без ссылки) |
| `gh repo create` | Создать репозиторий на GitHub |
| `gh repo view --web` | Открыть репозиторий в браузере |
| `gh browse` | Открыть репозиторий (или файл) в браузере |

## Pull request'ы — главное

| Команда | Что делает |
|---|---|
| `gh pr create` | Создать PR из текущей ветки (спросит название и описание) |
| `gh pr create --fill` | То же, название и описание берёт из коммитов |
| `gh pr create --draft` | Создать черновик PR |
| `gh pr view --web` | Открыть PR текущей ветки в браузере |
| `gh pr list` | Список открытых PR |
| `gh pr checkout <номер>` | Перейти на ветку чужого PR |
| `gh pr checks` | Статус проверок (CI) |
| `gh pr merge` | Влить PR (спросит способ) |
| `gh pr merge --squash` | Влить, склеив коммиты в один |
| `gh pr merge --auto` | Влить автоматически, когда пройдут проверки |
| `gh pr merge --admin` | Влить, обойдя ограничения — **только если у тебя есть права администратора** |

## Прочее

| Команда | Что делает |
|---|---|
| `gh issue list` / `gh issue create` | Список задач / создать задачу |
| `gh status` | Что происходит в твоих репозиториях: PR, задачи, упоминания |
| `gh ssh-key add <файл.pub>` | Добавить SSH-ключ в аккаунт |
| `gh ssh-key list` | Список ключей в аккаунте |

## Полная документация

Все команды gh: **<https://cli.github.com/manual/>**. В терминале: `gh <команда> --help`, например `gh pr merge --help`.
