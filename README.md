# AVIS TV — tutorials

Текстовые инструкции к видео канала **AVIS TV**. Одна папка — одно видео: что показываем в кадре, команды, скриншоты и схемы.

## Видео

| № | Тема | Инструкция |
|---|------|------------|
| 01 | Настройка git и gh (macOS, Windows, Ubuntu) | [videos/01-git-gh-setup](videos/01-git-gh-setup/README.md) |

## Структура

```
avis-tv-tutorials/
├── README.md              # этот индекс
├── _template/             # заготовка для нового видео
│   ├── README.md
│   └── images/
└── videos/
    └── NN-короткое-имя/   # одно видео = одна папка
        ├── README.md      # инструкция
        └── images/        # скриншоты (.png) и схемы (.svg)
```

## Новое видео

```bash
cp -R _template videos/02-название
```

Затем заполнить `videos/02-название/README.md` и добавить строку в таблицу выше.

## Правила

- Имя папки: `NN-латиницей-через-дефис`, номер по порядку выхода.
- Инструкция — коротко, без воды: команда → результат → следующий шаг.
- Картинки лежат в `images/` рядом с инструкцией, имена латиницей (`git-install-mac.png`).
- Скриншоты без личных данных: токены, e-mail, коды, приватные репозитории.
